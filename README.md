# 🎧 英语影子伴侣 (English Shadow Companion)

> **打字学英语的桌面随身伴侣 · 原生 Apple 风格设计 · 沉浸式情境习得**
>
> 专为**“在日常打中文时顺便学英语”**而设计。你在微信、浏览器、Word 里正常打字发中文，屏幕右上角静默浮现地道英文对照与重点词汇拆解。

---

## ✨ 核心特性

- 🍏 **原生 Apple 设计美学**：
  - 经典 macOS **红黄绿三色红绿灯**交互；
  - **液态磨砂玻璃（Liquid Glassmorphism）** 与 22px 超椭圆（Squircle）圆角；
  - 完美适配 Windows 高 DPI 缩放与原生中英文高清字体回退（`Segoe UI` + `微软雅黑 UI`），杜绝方块字与乱码；
  - 一键折叠为**苹果灵动岛（Dynamic Island）微型胶囊**。
- ⚡ **无感自动伴随（零打扰输入）**：
  - 不需要打开任何独立输入框，**完全不改变你原本的中文打字和发消息习惯**；
  - 智能感知打字停顿与 **Enter 回车发送**，自动提取最新句段并生成双语微卡片。
- 📖 **核心搭配与生词拆解**：
  - 自动提炼英文译文中的 1~3 个核心生词/地道搭配与中文释义；
  - **单词可点读**：鼠标直接点击任一单词胶囊，单独朗读该单词发音。
- 🔊 **纯正语音发音**：
  - 支持一键朗读整句地道英文发音；
  - 支持顶部标题栏一键切换【自动朗读: 开/关】。
- 🎯 **全局极简快捷键**：
  - <kbd>F8</kbd> 或 **连续双击两次 <kbd>Ctrl</kbd>**：立即学习当前输入框或选中的文本。

## 🛠️ 项目架构

```
type_english_companion/
├── main.py          # 核心控制器，协调监听器、UI 与翻译引擎
├── ui.py            # 原生 Apple 风格的 PyQt6 悬浮卡片组件
├── monitor.py       # 智能输入监听引擎 (UIAutomation + Enter检测 + 剪贴板)
├── translator.py    # 高速翻译与核心词汇批量提炼模块
├── speech.py        # 异步非阻塞 Windows SAPI 语音朗读引擎
├── launch.vbs       # 静默无黑框后台启动脚本
├── run.bat          # 便捷启动批处理
└── requirements.txt # Python 依赖列表
```

---

## 🚀 快速开始

### 1. 安装依赖

确保已安装 Python 3.10+：

```bash
pip install -r requirements.txt
```

### 2. 运行伴侣

直接双击 `run.bat`，或在终端运行：

```bash
python main.py
```

若需无黑框后台静默启动，运行 `launch.vbs` 即可。

## ⌨️ 快捷键与操作指南

| 动作 | 触发方式 | 功能说明 |
| :--- | :--- | :--- |
| **拖拽卡片** | 鼠标按住顶部标题栏拖动 | 随意移动到屏幕舒适位置，位置自动持久化记忆 |
| **折叠灵动岛** | 点击黄色红绿灯按钮 `–` | 收起为极简小胶囊，有新打字输入时自动展开 |
| **整句朗读** | 点击 `[朗读]` 按钮 | 播放当前句子的标准英文发音 |
| **点读单个生词** | 鼠标点击生词胶囊标签 | 单独听取该生词或短语的标准发音 |
| **一键复制英文** | 点击 `[复制]` 按钮 | 复制英文到系统剪贴板，带绿色动态反馈 |
| **即刻学习当前句** | 按 <kbd>F8</kbd> 或连按两次 <kbd>Ctrl</kbd> | 强制解析当前输入框或剪贴板内容 |
| **关闭退出** | 点击红色红绿灯按钮 `×` | 安全退出程序 |
